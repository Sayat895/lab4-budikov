# Автоматизация учета работы филиала

Учебный проект для лабораторной работы № 4 по теме «Интерфейс». Приложение помогает вести список сотрудников и филиалов, регистрировать смены и формировать отчет в Excel.

Графический интерфейс сделан на **PyQt5**, данные хранятся в **PostgreSQL**, а Docker Compose запускает приложение и базу вместе. Окно PyQt5 открывается в браузере через noVNC, поэтому для работы не требуется настраивать X11 или устанавливать GUI на Windows.

## Запуск

Нужен установленный и запущенный Docker Desktop с Linux containers.

Откройте PowerShell в папке проекта и выполните:

```powershell
Copy-Item .env.example .env
notepad .env
docker compose up --build -d
```

Перед запуском задайте в `.env` собственные пароли базы данных и двух учетных записей приложения вместо значений `replace-with-a-private-...`. Файл `.env` исключен из Git и не должен публиковаться. При повторном запуске приложения учетные записи синхронизируются со значениями из этого файла.

Для локальной учебной конфигурации используются логины `director` (руководитель) и `senior_cashier` (старший кассир); пароли хранятся только в локальном `.env`, поэтому в публичной копии проекта они не приводятся.

После запуска откройте в браузере:

**[Открыть приложение](http://localhost:6080/vnc.html?autoconnect=true&resize=scale&path=websockify)**

Все операции с данными филиала выполняются в этом приложении — отдельная веб-панель базы для повседневной работы не нужна.

При первом запуске используются логины и пароли, заданные в `.env`. Не публикуйте этот файл и не используйте локальные учебные учетные записи в других системах.

## Что умеет приложение

- **Обзор:** показывает количество активных сотрудников, сегодняшние смены и итоги за месяц.
- **Сотрудники:** руководитель добавляет, редактирует и удаляет карточки персонала; можно указать должность, телефон и филиал.
- **Смены:** кассир регистрирует сотрудника, дату, тип смены, часы, недостачу и излишек. Руководитель может исправлять и удалять записи.
- **Филиалы:** руководитель ведет список филиалов и их адресов.
- **Начальный список:** после настройки локальной базы в ней можно хранить сотрудников и филиалы вашего варианта; персональные данные не входят в публичный репозиторий.
- **Отчет:** руководитель выбирает период и сохраняет Excel-книгу `.xlsx` со сменами и списком сотрудников.
- **Роли:** старший кассир видит данные своего филиала и добавляет смены; руководителю доступны сводные данные и управление.
- **Хранение:** данные остаются в Docker-томе `pg_data` после перезапуска контейнеров.

## Как устроен проект

| Компонент | Назначение |
|---|---|
| `app/main.py` | PyQt5-интерфейс, диалоги, формы, отчеты и проверки ввода |
| `app/db.py` | Подключение к PostgreSQL, схема таблиц, авторизация и операции с данными |
| `app/novnc_server.py` | Веб-доступ к окну PyQt5 через браузер |
| `app/supervisord.conf` | Запуск виртуального экрана, VNC и приложения в контейнере |
| `docker-compose.yml` | Совместный запуск приложения и PostgreSQL |

Используются Python 3.12, PyQt5, PostgreSQL 15, psycopg2, openpyxl, aiohttp и Docker Compose. Дизайн выполнен в спокойной бордово-золотой палитре по мотивам оформления Magnum; это учебный интерфейс, а не официальный продукт компании.

## Проверка и управление

Посмотреть состояние контейнеров:

```powershell
docker compose ps
```

Посмотреть сообщения приложения:

```powershell
docker compose logs -f app
```

Запустить тесты после запуска базы и контейнера приложения:

```powershell
docker compose exec app python -m unittest discover -s tests -v
```

Остановить контейнеры, сохранив данные:

```powershell
docker compose down
```

Запустить снова:

```powershell
docker compose up -d
```

Не добавляйте `-v` к `docker compose down`, если нужно сохранить базу данных. Не публикуйте `.env`, пароли и персональные данные сотрудников.
